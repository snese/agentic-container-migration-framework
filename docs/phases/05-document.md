# Phase 5: Document

**MAP alignment:** cross-cutting (post-engagement).

**Why this phase matters:** Skip Document and the next engagement starts from scratch — the same gotchas get rediscovered, the same patterns get re-invented, and the framework stops improving. Phase 5 is the only place where lessons learned become reusable assets (case study, adapter PRs, framework backlog). The next customer's Phase 1 quality is set by *this* customer's Phase 5 discipline.

**Goal:** Capture lessons learned as a reusable case study and feed improvements back into the framework.

## Inputs
- All artifacts from Phases 1–4

## Activities
- Anonymize customer-specific details
- Extract reusable patterns into framework adapters
- Write public-facing case study
- Identify framework gaps → backlog items

## Outputs
- `docs/case-studies/<slug>.md`
- PRs to framework adapters with new patterns
- Framework backlog updates

## Exit Criteria
- [ ] Case study reviewed by customer (anonymization OK)
- [ ] At least one reusable pattern contributed back
